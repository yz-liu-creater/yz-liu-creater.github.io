Overview

Compression is an allocation problem.

Fixed rules decide the representation before they know where the cache matters. GraceKV reverses that order: every candidate cache entry competes for one shared physical-entry budget.

KV merging

Coverage and resolution

The cache budget flows toward the layer, head, region, and resolution with the highest marginal utility.

Abstract

As large language models process increasingly long contexts, KV cache storage and repeated access become a major bottleneck. GraceKV formulates compression as global resource allocation under a fixed cache budget. Each layer-KV-head-slot combination receives a progressively refinable prototype tree: adding a root expands coverage, while splitting a selected node improves local resolution. Candidate actions compete globally, allowing the final cache to adapt across model components and context regions. The method needs no additional training, runs entirely on the GPU, and remains robust at compression ratios up to 128× across diverse long-context tasks.

Method

Shape the cache, price each refinement, spend globally.

A unified tree representation turns coverage and resolution into comparable actions. Value flows upward through every tree; budget flows to the most useful action across all trees.

  1. 01

    Build refinable trees

    Curvature and token surprisal define semantic slots. Leaves preserve exact K/V pairs; internal nodes represent contiguous spans with weighted prototypes.

  2. 02

    Estimate marginal utility

    Direct and multi-hop relevance, attention distortion, and head sensitivity determine the value of adding coverage or increasing resolution.

  3. 03

    Allocate one shared budget

    Add and Split actions from every layer, KV head, and slot enter a global priority queue. The highest-return action wins each physical cache entry.

Add

Admit a new root prototype to extend information coverage.

Split

Replace a prototype with its children to increase local resolution.

Floor

Keep a small set of high-value singletons exact under the same budget.
